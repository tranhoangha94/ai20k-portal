# AI20K Portal

Cổng học viên (student portal) cho Chương trình Đào tạo Nhân tài AI Thực Chiến — Tập đoàn Vingroup & Trường Đại học VinUni.

Lối tắt tới VLearn, Phoenix, Discord và liên hệ chương trình (xin nghỉ phép / hỗ trợ email, mật khẩu).

Xây bằng Next.js (App Router).

## Chạy thử

```bash
npm install
npm run dev
```

Mở http://localhost:3000.
